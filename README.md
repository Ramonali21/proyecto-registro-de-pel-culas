# Sistema de gestión de peliculas

El sistema de gestion de peliculas permite el registro de nuevas peliculas, buscarlas, listarlas, ademas de modificarlas y eliminarlas. Tambien cuenta con un sistema de promedio y una interfaz por terminal bonita.

## Funcionamiento:

El proyecto esta escrito unicamente en Python; como metodo de persistencia se utilizó JSON, el programa utiliza metodos de manejo de archivos JSON para dar como resultado el funcionamiento optimo del programa. Se utilizó la IA principalmente para la resolucion de dudas, ademas de explicacion de errores cuando el programa fallaba.

Para arrancar el programa, se ejecuta el siguiente comando:

```bash
python main.py
```
